Getting Started

  1. Serve the project (required for MIDI/microphone access): 
    npx serve
# or
python -m http.server 8000
# or use VS Code Live Server
  2. Open http://localhost:3000 (or your server URL) in a modern browser
  3. Load an audio file using the folder button (📁) in the Audio Player panel
  4. Connect a MIDI keyboard (auto-detected via Web MIDI API) or enable Microphone Input toggle in the Piano Keyboard panel
  5. Play along — notes appear on the keyboard and in the transcription log
Note: This app requires a secure context (HTTPS or localhost). The file:// protocol won't work for MIDI or microphone access.

Audio Player

Loading Audio

Click the 📁 Load Audio File button to select an MP3 or WAV file from your computer. The waveform will be displayed once loaded.

Playback Controls

  • ▶ Play / ⏸ Pause — Start or pause playback
  • ⏩ Rewind / ⏩ Forward — Seek backward/forward by 5 seconds
  • Speed slider — Adjust playback speed from 0.25× to 1.0× (pitch-preserving)
  • Volume slider — Control output volume

A-B Looping

  • Press A to set the loop start point
  • Press B to set the loop end point
  • The loop region is highlighted on the waveform
  • Press ✕ Loop to clear the loop
  • Loop seamlessly repeats the selected section

Waveform

The waveform visualizes the loaded audio. The playhead (vertical line) shows current position. The loop region (shaded area) shows the A-B loop range when set.

Piano Keyboard & Input Modes

On-Screen Keyboard

  • 2-octave range: C4 to B5 (24 keys) by default
  • Click/touch keys to play notes with synthesized piano tones
  • Keys light up when notes are received via MIDI, microphone, or click
  • Each key shows its note name (e.g., C4, C♯4, D4)
  • Full keyboard accessibility: Tab to navigate, Space/Enter to play
  • Keyboard range: use the ▼/▲ buttons (or Z/X keys) to shift the on-screen keyboard up or down by octaves (C1–B2 through C6–B7). The key labels update to match the new range.

Input Modes

Toggle between input modes using the Mic Input checkbox in the Piano Keyboard panel header:

MIDI Input (default)
Uses Web MIDI API. Connect a MIDI keyboard — it's auto-detected. Status shows in the indicator (e.g., "MIDI: 1 device connected"). Handles Note On/Off with velocity.
Microphone Input
Uses MediaDevices API + Web Audio API for pitch detection via autocorrelation. Works with acoustic piano or voice. Frequency range: ~65–1000 Hz (C2–C6). Requires microphone permission.
Tip: For best microphone results, minimize background noise and position the mic close to your instrument.

Transcription Log

  • Real-time logging of every note played
  • Automatic chord grouping: Notes played within 50ms are grouped as a chord
  • Each entry shows: timestamp, note(s) with octave, and source (MIDI/Audio/Click)
  • Chord entries have a teal left border
  • Clear — removes all entries
  • Export — downloads the log as a JSON file

Export Format

The exported JSON contains an array of entries, each with:

{
  "time": 12.345,
  "notes": ["C4", "E4", "G4"],
  "source": "midi",
  "velocity": 0.8
}

Keyboard Shortcuts

← / → Seek -1s / +1s

Z / X Shift on-screen keyboard range down / up one octave
Tab Navigate piano keys (when keyboard focused)
Space / Enter Play focused piano key

Tips for Effective Practice

  • Start slow: Use 0.5× or 0.75× speed to hear individual notes clearly
  • Loop difficult passages: Set A-B loop on a challenging section and repeat
  • Use the transcription log: Export your practice sessions to track progress
  • Sing along: Try singing the melody before playing — strengthens pitch memory
  • Practice intervals: Focus on hearing the distance between notes, not just absolute pitch
  • MIDI vs Mic: MIDI is more accurate; microphone is great for acoustic piano practice
